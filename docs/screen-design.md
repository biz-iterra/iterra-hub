# 　ITERRA CRM 画面設計書

## 0. デザイン仕様

ITERRAデザインシステム（`design-system-temp`）のトークンに準拠して構築する。
ハードコードした色値・余白・角丸・影は禁止。すべてトークン経由で参照する。

### 0.1 参照元

- カラートークン: `design-system-temp/tokens/colors.ts`
- タイポグラフィ: `design-system-temp/tokens/typography.ts`
- スペーシング: `design-system-temp/tokens/spacing.ts`
- 角丸: `design-system-temp/tokens/radius.ts`
- エレベーション: `design-system-temp/tokens/elevation.ts`
- Z-Index: `design-system-temp/tokens/zindex.ts`

### 0.6 デザインルール（デザインシステム準拠）

1. **囲み枠線の禁止** — カード・テーブル・セクションを `border` で囲まない。要素の区別は**余白・タイポグラフィ・色・影**で表現する。テーブルの行区切り線（`borderBottom: sumi100`）は許可
2. **ボタンはピル形** — `border-radius: full`（9999px）。ITERRA標準
3. **ホバーでエレベーション変化** — カード等はホバー時に影が一段上がる（`low` → `medium`）
4. **フォーカスはsoleil** — キーボードフォーカス時は `soleil` のフォーカスリング
5. **色はセマンティックトークン経由** — `#3C3F58` ではなく `terra` で参照。CSS変数形式: `var(--color-terra)`

## 4. 共通UIパターン

### 4.1 検索セレクト（search/select）

アカウント・カンパニー・コンタクト等の選択UIに使用。

- テキスト入力でインクリメンタル検索
- コード + 名称を表示
- 選択後はバッジとして表示

### 4.2 一括操作

テーブルのチェックボックス選択後に表示:

- 担当者一括変更
- ステータス一括変更（対応するエンティティのみ）
- CSV エクスポート

### 4.3 削除/無効化

- トランザクションデータ: 論理削除（is_active=FALSE）。確認ダイアログ表示
- ディール: 削除不可。クローズのみ
- マスタデータ: 無効化（is_active=FALSE）。参照されている場合は警告

### 4.4 バリデーションエラー

- フィールド直下に赤文字でエラーメッセージ
- 送信時のサーバーエラーはトースト通知

### 4.5 ロール別表示制御

| 要素           | member         | manager        | admin |
| -------------- | -------------- | -------------- | ----- |
| 一覧の表示範囲 | 自分の担当のみ | 全件           | 全件  |
| 編集ボタン     | 自分の担当のみ | 自分の担当のみ | 全件  |
| 削除/無効化    | -              | -              | ○    |
| 契約メニュー   | 非表示         | ○             | ○    |
| 管理メニュー   | 非表示         | 非表示         | ○    |
| 金融機関情報   | 非表示         | 閲覧のみ       | CRUD  |
