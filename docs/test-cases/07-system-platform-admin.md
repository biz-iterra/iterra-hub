### DSH-01: KPI カードの値が seed データと一致する

- 対象: `/dashboard`
- 権限: admin（RLS で全件が見える前提の基準値）
- 事前条件: seed（03-dev-samples.sql）投入直後で追加データなし
- 手順:
  1. admin でログインし `/dashboard` を開く
  2. SQL で基準値を取得して照合する:
     - 進行中ディール: `SELECT count(*) FROM deals WHERE closed_at IS NULL;`
     - 進行中 合計金額: `SELECT sum(amount) FROM deals WHERE closed_at IS NULL;`
     - 今月クローズ: `SELECT count(*) FROM deals WHERE closed_at BETWEEN 月初 AND 月末;`
     - 取引先数 / 連絡先数 / 事業者情報数: 各テーブルの `deleted_at IS NULL` の件数
- 期待結果:
  - 6 枚の KPI カード（進行中ディール / 進行中 合計金額 / 今月クローズ / 取引先数 / 連絡先数 / 事業者情報数）が SQL の値と一致する
  - 金額は「￥1,234,567」形式（ja-JP 通貨表記）
- 自動化区分: 手動（SQL 照合を伴うため）
- 備考: ディール系 KPI は `deleted_at` を除外していない（§3 懸念 5）。論理削除したディールがある環境では値がずれる

  4. OS の「視差効果を減らす」を有効にして 1. を繰り返す
- 期待結果:
  - エラートーストは 5 秒時点では残り、約 10 秒（`AUTO_DISMISS_MS.error = 10000`）で自動消滅する
  - 閉じるボタンではいつでも即座に消える
  - success トーストは約 4 秒（`AUTO_DISMISS_MS.success = 4000`）で自動消滅する
  - 消えるとき、右下を基点に 0.9 倍へ縮みながらフェードアウトする（`transformOrigin: bottom right`）
  - 「視差効果を減らす」時はアニメーションなしで即座に消える
- 自動化区分: 自動(Playwright)（4. は手動）

### CMN-13: スクロールするのは本文だけで、外枠は動かない

- 対象: `src/components/layout/app-shell.tsx` の `<main>`
- 権限: 認証済み（ロール不問）
- 手順:
  1. `/activities`（縦に長い一覧）を開き、マウスホイールで下までスクロールする
  2. `/leads/new` のような縦に長いフォームでも同じ操作をする
- 期待結果:
  - サイドバーとヘッダーが画面上の同じ位置に留まる
  - 本文の下に余白（真っ白な帯）が現れない
  - `document.documentElement.scrollHeight` が `clientHeight` を超えない
- 補足:
  - **`<main>` の `position: relative` が要件。** 外すと `.sr-only`（`position: absolute`）の
    包含ブロックが `<html>` になり、表示領域より下に出た分だけ文書がスクロールできるようになる。
    外枠ごと画面が流れて崩れる（T-0089。本番のアクティビティ一覧で 782px）
  - スクロールバーはシステム全体で非表示なので、**ずれていても「スクロールできる」ことが見えない**。
    症状は「下に真っ白な帯が出る」「サイドバーが上へ消える」として現れる
- 自動化区分: 自動(Playwright) — E2E-19

### CMN-14: モーダル・ドロワーを開いている間は背面が動かない

### CMN-15: 背の高いモーダルでも上端に到達できる
